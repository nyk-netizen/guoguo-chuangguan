# 果果闯关 · 怎么加字

字库不在网页里改，在 Claude Code 里改。对它说一句：

> 把「X、Y、Z」补进果果闯关的字库

Claude Code 照下面的步骤做，做完给家长过目，家长说可以了才算进库。

## 一个字要补哪些东西

| 内容 | 写在哪 | 必须吗 |
|---|---|---|
| 拼音 `py`、形近干扰字 `near` | `字库补充.js` 的 `ZI['字']` | 必须 |
| 读音 `w_字`，例如「心，开心的心。」 | `lines.json` | 必须（没有就退回电脑语音） |
| 偷字怪念这个字 `b_c_字`：`"[云希·偷字怪] 这个字念，心！"` | `lines.json` | 必须（前缀会让配音自动换成偷字怪的声音） |
| 原画 `pic` + 甲骨文 `oracle` | `ZI['字']` | 只有象形字才给 |
| 拼字 `CHAINS.push(...)` + 讲法读音 `k_字` | `字库补充.js` / `lines.json` | 能拼才给 |
| 开局排在字墙前面 | `LIB_ORDER` | 家长点名的那批 |

## 规矩（以前犯过错或差点犯错的地方）

1. **甲骨文必须对照字源网站画**（汉典 zdic.net 的「字源字形」、中研院小学堂），不许凭印象画。查不到的，就不给 `oracle`，这个字也就不进连线。
2. **原画只给真正的象形字。** 形声字（狗、猪、路、园……）没有「画变成字」这回事，硬画是骗孩子。
3. **简化字要特别小心。** 比如「叶」：树上长叶子那幅古字是繁体「葉」的来历，简化字的叶（口+十）跟它不是一回事，所以叶不进连线。
4. **拼字要分清是哪一类，讲法不一样，别讲串：**
   - `x` 会意：真的字源，故事照讲（木+木=林）
   - `s` 形声：「一半表意思、一半告诉你怎么念」，不编故事（囗+元=园）
   - `j` 助记：不是字源，只帮着记住字形（口+木=呆，呆本来是「保」的异体）
   - `w` 古书讲法：《说文》这么讲但学界有争议（八+厶=公）
5. **多音字**的读音要写成词，不能只念单字（「长短的长」，不能只写「长」）。
6. **干扰字**避开只差比例或一两笔的字（曰/日、未/末、本/木），五岁半分不出来，会挫败。
7. **大字**（方块搭的字）不用管：笔画太多的字会自动不搭（填充率超过 0.40 就跳过）。

## 改完要跑

```bash
cd src
python3 gen_audio.py   # 只生成新加的配音；改了某句文字，先删掉对应的 mp3
python3 build.py          # 生成仓库根目录的 index.html
```

然后打开成品，在字墙上点新字，看连线里的画和甲骨文、工作台里的拼法对不对。**家长看过再给孩子玩。**
