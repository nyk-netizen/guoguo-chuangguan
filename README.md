# 果果闯关 · 今天的字

**孩子今天学了几个字？家长点 3–5 个，就生成一局像素闯关，玩一遍把这几个字复习一遍。**

👉 **在线玩：** https://nyk-netizen.github.io/guoguo-chuangguan/ （电脑浏览器，方向键走、空格跳、鼠标点字）
也可以下载 `index.html` 双击打开，断网也能玩、能出声。

## 一局里有什么

1. **今天的字**：五张字卡挨个念一遍
2. **路上**：听到哪个字，就去顶写着那个字的方块；三扇门，只有写着那个字的能推开
3. **大字**：路上有用方块搭成的巨大的字（森林里是树篱、城市里是砖、山里是石头、海边是珊瑚），横画的顶面能站上去
4. **停下来用手**：
   - 找字：一条街上，把念到的字都找出来
   - 连线：古时候的字（甲骨文）↔ 今天的字，只有真正的象形字才进这一关
   - 工作台：把字拼起来，木+木=林、人+木=休
5. **偷字怪**：它把今天的字偷去当盔甲。听音顶字砖，一块块打掉；路上错得多的字会多问一次。最后它举着一个字故意念错，要孩子来抓
6. **终点在现实里**：孩子在家里、路上真的认出一个字，爸爸点亮它，这个字才住进他的**认字墙**

## 为什么做

我五岁半的儿子认字是「换个位置就忘」：他记住的是字待在哪儿，不是字长什么样。所以同一个字要换字体、换颜色、换大小、换地方，反复出现；还要先听到音，再去找形。

游戏擅长让重复不烦人，但我不想让它变成另一个停不下来的东西。所以它结束在现实里：**玩得多，墙上的字不会多；在外面认出来，才会多。**

## 几条规矩

- 没有红叉，不扣分，没有积分。顶错了，偷字怪只会嘿嘿笑一声，上面把字亮出来
- 字只歪 ±8°：中文对方向很敏感，大角度练的是空间旋转，不是认字
- 世界是像素的，**字不是**：字一糊，笔画就错了
- 甲骨文要对照字源网站画，查不到就不画；形声字（狗、路、园……）不编「画变成字」的故事；助记（口+木=呆）会标明「不是字源」
- 笔画太多的字不搭成大字：12×12 的格子装不下，搭出来笔画是错的
- 不联网、不上传，认字墙只存在这台电脑的浏览器里
- 主角果果是一个像素小人，不是孩子的照片

## 字库怎么加

开局的字墙上有 38 个字。要加新字，在 Claude Code（或别的能改代码的 agent）里说：

> 把「X、Y、Z」补进果果闯关的字库

agent 照 [`src/怎么加字.md`](src/怎么加字.md) 的规矩补：拼音、组词读音、形近字，象形字的原画和甲骨文，能拼的字的拼法，再录好配音、重新打包。**家长看过再给孩子玩。** 字库外的字也能直接玩，只是没有连线和工作台，读音用电脑自带的语音。

## 文件

```
index.html          打包好的游戏（单文件，配音已嵌入）
src/game.html       游戏主体
src/字库_基础.js     基础字库（23 字）
src/字库补充.js      后来补的字，加字就改这里
src/lines.json      所有配音的文字（edge-tts 晓晓 / 云希）
src/audio/          配音 mp3
src/build.py        打包：python3 build.py
src/gen_audio.py    生成配音：python3 gen_audio.py
src/怎么加字.md      加字的规矩
```

## 姊妹项目

**[好奇心工地 curiosity-site](https://github.com/nyk-netizen/curiosity-site)**：家长借 AI，把孩子的「为什么」做成一本查证过的绘本。

两个项目是同一套做法的两种形态：好奇心工地接住孩子的问题，果果闯关复习孩子今天学的字。AI 负责生成，家长看过才放行；不用现成的 IP 角色；结束在现实里，读完去问新问题，玩完去外面找字。
